True Health Content Report

An internal reporting tool of True Health Co., Ltd. (brands True Health and JiJi, Vietnam). It helps our marketing team track the performance of the company's own TikTok accounts and Facebook pages: number of videos posted per day and month, views, likes, comments and shares.

Each account owner signs in with TikTok and authorizes the tool themselves. The tool only reads data; it never posts, comments or changes anything. Data is stored in a private Google Sheet visible only to our marketing team.
